# Бесплатный хостинг для бота (итог, октябрь 2026)

Бот работает через MTProto (Telethon), webhook ему не нужен — ему нужен
долгоживущий процесс где-то в интернете. Serverless (Vercel, Netlify,
Cloudflare Workers) не подходят: там нет постоянно работающего процесса.

## Что в итоге выбрано

**Bot-Hosting.net, тариф Free** — бот уже развёрнут и работает.

- 256 МБ RAM, 25 % CPU, 512 МБ диска, 1 деплой;
- карта не нужна, аккаунт через email;
- сервер в Финляндии (`fi17.bot-hosting.cloud`), доступен из России;
- деплой прямо из публичного GitHub-репозитория;
- токен и прочие секреты — в переменных окружения панели, не в коде.

Docker-деплой из `Dockerfile` там не используется: платформа сама создаёт
Python-окружение и ставит зависимости из `requirements.txt`, затем запускает
`main.py`. Поэтому в коде поддержан `SERVER_PORT` — панель отдаёт его для
health-сервера.

### Продление (важно)

Бесплатный сервер живёт 4 дня, потом ещё 3 дня «льготных», затем его удаляют
(бэкап хранится сутки). Продление — только вручную, в панели:

1. https://bot-hosting.net/a → **Оплата** (Billing);
2. зелёная кнопка **Renew free plan**;
3. дождаться проверки бота → **Renew for 4 days**.

Через API продление недоступно — только эта кнопка. Проще всего поставить
напоминание в телефоне раз в 3 дня.

## Почему не другие варианты

| Вариант | Итог |
| --- | --- |
| **Render Free** | `api.render.com` блокируется провайдером из России — дашборд не работает, сервис не создать. Даже если поднять, управлять нечем. |
| **Bothost.ru Starter** | Бесплатный тариф отключён («нет свободных мощностей»). Аккаунт есть, бот не создаётся. Платный — 99 ₽/мес. |
| **Hugging Face Spaces** | Работает из России, 16 ГБ RAM, без продлений, но Space засыпает после ~48 ч без HTTP-запросов (нужен внешний пинг) и аккаунт там не заведён. Запасной вариант. |
| **Oracle Cloud Always Free** | Нужна карта (иностранная), регистрация сложная. |
| **Their/Beget/Timeweb/Amvera** | Только пробный период, потом 150–500 ₽/мес. |
| **Старый Android + Termux** | Бесплатно и без лимитов, но нужен телефон 24/7 в розетке и Wi-Fi (см. [termux.md](termux.md)). |
| **Этот ПК + Планировщик Windows** | Работает, но только пока компьютер включён и пользователь вошёл в систему. |

## Данные

На Bot-Hosting диск сохраняется между перезапусками: база лежит в
`/home/container/data/chess.db`, лог — в `/home/container/data/bot.log`.
При удалении сервера (после 7 дней без продления) данные пропадают.

## Если бот не отвечает

1. Панель → деплой `chess-bot` → **Console/Логи**; ищем `Бот запущен`.
2. Лог `Conflict: terminated by other getUpdates request` означает, что где-то
   запущена вторая копия с тем же токеном — остановите её (например, задачу
   Планировщика `ChessBot` на ПК).
3. `TOKEN_INVALID` — токен в переменных окружения панели устарел/заменён в
   @BotFather, обновите `BOT_TOKEN`.
4. Кончилось место/память — панель показывает лимиты на главной.

## Полезные команды API

База: `https://bot-hosting.net/api/v1`, заголовок `Authorization: Bearer <ключ>`.

```bash
# состояние, логи, ресурсы одним запросом
GET  /deployments/<id>/diagnose?waitSeconds=45
# последние строки лога
GET  /deployments/<id>/logs?size=200&waitSeconds=30
# перезапуск
POST /deployments/<id>/power      {"action":"restart"}
# подтянуть свежий код из GitHub и перезапустить
POST /deployments/<id>/sync
```

Ключ и id деплоя — в `data/cloud-credentials.txt` (папка в `.gitignore`).
