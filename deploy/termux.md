# Бот на старом Android-телефоне (Termux)

Телефон подходит как «домашний мини-сервер»: боту не нужны входящие порты,
только постоянный интернет и папка `data/`. Ниже — установка через Termux
с автозапуском после перезагрузки.

**Требования:** Android 7.0+ (лучше 9+), 1 ГБ ОЗУ, ~150 МБ свободного места,
зарядка 24/7. На iOS так нельзя: система не даёт держать фоновый процесс.

> ⚠️ С одного токена может работать только **один** экземпляр бота.
> Перед запуском на телефоне останови бота на компьютере
> (`Ctrl+C` в окне, где он запущен), иначе оба будут мешать друг другу.

## 1. Что поставить на телефон

Ставь **не из Google Play** — там версия Termux устарела и больше не обновляется.

1. Установи [F-Droid](https://f-droid.org/) (магазин свободных приложений, APK).
2. Из F-Droid поставь:
   - **Termux** — терминал, в нём живёт бот;
   - **Termux:Boot** — запускает бота после перезагрузки телефона.
3. Открой Termux один раз и разреши уведомления (нужны для `wake-lock`).

## 2. Скопировать проект на телефон

Собери архив на компьютере (в PowerShell, из папки проекта):

```powershell
Compress-Archive -Path main.py,requirements.txt,.env.example,chessbot,assets,deploy `
  -DestinationPath dist\chessbot-phone.zip -Force
```

Дальше любым способом: кабель (папка `Download`), Telegram «Избранное»,
Google Drive. В Termux:

```bash
termux-setup-storage          # разрешить доступ к памяти телефона
pkg update -y && pkg install -y unzip
cd ~
unzip ~/storage/downloads/chessbot-phone.zip -d chessbot
cd chessbot
```

## 3. Установить зависимости

```bash
bash deploy/termux-install.sh
```

Скрипт ставит `python`, `python-pillow` (готовый Pillow под Android) и
pip-пакеты `python-chess`, `telethon`, `python-dotenv`, `python-socks`.

⚠️ Не делай `pip install -r requirements.txt`: строку `Pillow` под Android
пришлось бы собирать из исходников, это часы и обычно ошибка. Пакет
`python-pillow` из Termux уже содержит нужный модуль `PIL`.

## 4. Заполнить `.env`

```bash
nano .env
```

Минимум:

```
BOT_TOKEN=123456789:AA...
FINISHED_GAME_TTL=600
```

- **`MTPROXY` с компьютера надо убрать** (`127.0.0.1:1443` на телефоне
  указывает в никуда). Если Telegram с телефона не открывается, включи
  VPN-приложение (в настройках Android — «Постоянная VPN») или пропиши
  рабочий `PROXY_URL`/`MTPROXY`.
- Сессию Telethon копировать не нужно: бот логинится по токену сам,
  `data/chessbot.session` создастся при первом запуске.
- Старые партии можно перенести: скопируй `data/chess.db` в `~/chessbot/data/`.

Сохранить в nano: `Ctrl+O`, `Enter`, `Ctrl+X`.

## 5. Первый запуск вручную

```bash
termux-wake-lock        # не давать Android «усыплять» Termux
python main.py
```

В логе должно появиться `Бот запущен: @skldlgkjsjskfkkfheja_bot`.
Проверь бота в Telegram (в том числе инлайн-режим). Остановить: `Ctrl+C`.

## 6. Автозапуск и работа в фоне

`deploy/termux-install.sh` уже создал скрипт автозапуска
`~/.termux/boot/start-chessbot.sh`. Он делает `termux-wake-lock`, заходит
в `~/chessbot` и держит бота в цикле: если процесс упадёт, он поднимется
через 10 секунд.

Осталось разрешить фоновую работу, иначе Android убьёт Termux:

1. **Termux:Boot** — открыть приложение один раз (этого достаточно).
2. Настройки Android → Приложения → **Termux** → Батарея →
   **«Без ограничений»** / «Не оптимизировать».
3. То же для **Termux:Boot**.
4. На Xiaomi/Redmi (MIUI), Huawei (EMUI), Samsung: дополнительно включить
   «Автозапуск» для Termux, а в списке недавних приложений — «закрепить»
   (замочек), чтобы система не выгружала.
5. Отключить энергосбережение («Режим экономии заряда») — оно убивает
   фоновые процессы.

Перезагрузи телефон и проверь: бот должен сам ответить в Telegram.
Лог: `tail -f ~/chessbot/data/bot.log`.

## 7. Обслуживание

```bash
pgrep -af "main.py"                  # запущен ли бот
tail -n 50 ~/chessbot/data/bot.log   # последние строки лога
pkill -f "main.py"                   # остановить
cd ~/chessbot && termux-wake-lock && python main.py &   # запустить снова
```

Обновление кода: заново распакуй архив в `~/chessbot` (папку `data/`
не трогай), затем `pkill -f main.py` и запусти снова.

## 8. Про «старый телефон» и батарею

- Держи телефон на зарядке постоянно — иначе бот умрёт при разряде.
- Аккумулятор под постоянной зарядкой греется и со временем раздувается.
  Сними чехол, положи на твёрдую поверхность, раз в пару месяцев проверяй
  крышку на вздутие. Если есть возможность — вынь аккумулятор и питай
  телефон от зарядки напрямую, либо используй умную розетку/таймер
  (заряд 2–3 часа в сутки телефону хватает).
- Ставь телефон туда, где не жарко и есть стабильный Wi-Fi.
- Пропал интернет/свет — бот просто офлайн; после возврата сети Telethon
  переподключится сам. Обычные партии сохранятся в SQLite, инлайн-партии
  живут в памяти и после перезапуска пропадут.

## 9. Если что-то не работает

| Симптом | Что делать |
| --- | --- |
| `Модуль PIL не найден` | `pkg install python-pillow`, не ставь Pillow через pip |
| `Не найден шрифт с шахматными символами` | убедись, что папка `assets/` с `DejaVuSans.ttf` скопирована |
| Ошибки соединения с Telegram | включи VPN/прокси, проверь `PROXY_URL`/`MTPROXY` |
| Бот молчит после перезагрузки телефона | открой Termux:Boot, проверь `~/.termux/boot/start-chessbot.sh`, настройки батареи |
| Бот «завис» | `pkill -f main.py`, затем запусти снова (цикл автозапуска поднимет сам) |
